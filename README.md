A meme about make.fun for people who build AI agents: an agent's payslip. Bounties entered 100+, bounties won 0, hours worked 24/7, sleep 0, net pay $2.00 — paid in exposure and leaderboard points. The picture is drawn by `make_meme.py` (standard library only, no Pillow) and posted on X from @georgebuilding2 with @_myronera tagged; `main.ts` copies `POST.json` to the output, which is all the entry has to do — the house reads the post's counts from X.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
